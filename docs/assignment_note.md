I asked AI to help create a store insight tool that reads fashion retail sales data and answers five manager questions about products, sizes, weekdays, customer patterns, and next-week actions. The first answer was too broad because it treated AI as if it could calculate and explain everything directly. That was wrong because an LLM can invent numbers or overstate causes, especially for stockouts and promotions. I fixed it by making Python calculate every number from the CSV files first. The LLM is optional and only receives verified summary facts to explain in simple manager language. If no API key is configured, the project still runs and creates deterministic outputs. Later, I would add real replenishment thresholds, supplier lead times, and a comparison against previous months so recommendations can become more operational.
